## Non-negotiable architecture rules

- **Composition over inheritance.** Entities are assembled from components
  (`HealthComponent`, `MovementComponent`, `HitboxComponent`). No deep class trees.
- **Signals flow up, calls flow down.** A parent may call methods on its children.
  A child NEVER calls a method on, or reaches into, its parent — it emits a signal.
- **Global Event Bus autoload** for cross-branch communication. Register it yourself in
  `project.godot` under `[autoload]`; never ask Simon to add it in the editor.
- **Data-driven design.** Game data lives in custom `Resource` classes saved as `.tres`
  files, not in hardcoded constants.
- **State machines** (finite or hierarchical) for any non-trivial behaviour. No
  `if state == "attacking"` chains.

## Coding standards (GDScript)

- Modern Godot 4 syntax only: `@export`, `@onready`, `await`, `signal`, typed arrays.
- **Strict static typing everywhere**: `var health: int = 100`, `func take(dmg: int) -> void:`.
- `_underscore_prefix` for private members and methods.
- `class_name` on anything referenced from another script.
- Tabs for indentation (Godot convention, matches `.editorconfig`).

## Zero-assistance asset generation

You are **forbidden** from asking Simon to draw art, model anything, find assets, or
download anything. Generate everything and **write it to disk yourself**:

- **2D art** → raw SVG XML written to `assets/sprites/*.svg`. Godot imports SVG natively.
  After writing SVGs, run the import step (below) so `.import` files are generated.
- **3D art** → built-in primitives (`BoxMesh`, `CapsuleMesh`) configured in `.tscn`, or
  procedural meshes via `ArrayMesh` / `SurfaceTool` in GDScript.
- **Textures, VFX, materials** → custom `.gdshader` files.
  NOTE: if this project uses the **Forward Mobile** renderer, do not use features Mobile
  drops (SDFGI, screen-space reflections, compositor effects, most `hint_screen_texture`
  tricks). If a design genuinely needs them, say so and propose switching
  `renderer/rendering_method` to `forward_plus` — do not switch it silently.
- **Audio** → generate procedurally at runtime (`AudioStreamGenerator`) or use
  `AudioStreamPolyphonic`. Never ask for sound files.

## Verification

**Exit codes are always 0 — they are meaningless here.** You must grep the output.

Syntax + type check a script:

```bash
$GODOT --headless --path . --check-only --script Foo.gd 2>&1 | grep -E "SCRIPT ERROR|Parse Error|ERROR:"
```

Import assets after writing SVGs or new resources:

```bash
$GODOT --headless --path . --import
```

Boot the project headless (catches missing NodePaths, bad signal connections, autoload
failures). No output from the grep = clean:

```bash
$GODOT --headless --path . --quit 2>&1 | grep -E "ERROR|SCRIPT ERROR|WARNING"
```

**Visual verification.** Headless has no rendering device — `RenderingServer.frame_post_draw`
never fires and the process hangs. To actually *see* the game, run it **windowed** (a
window appears on Simon's screen for a moment; that is expected) with a capture harness
that saves a PNG and quits, then read the PNG:

```bash
$GODOT --path . --resolution 800x480 res://debug/capture.tscn > /tmp/godot_run.log 2>&1 & \
  GPID=$!; sleep 10; kill $GPID 2>/dev/null; tail -5 /tmp/godot_run.log
```

Output lands in `~/Library/Application Support/Godot/app_userdata/<config/name>/`. Always guard
windowed runs with a background `&` + `sleep` + `kill`; a hung run costs two minutes.
`timeout` is not installed on this Mac.

## Conventions

```
assets/sprites/     SVG source art
assets/shaders/     .gdshader files
src/components/     reusable components (HealthComponent.gd, ...)
src/entities/       assembled entity scenes (.tscn + script)
src/systems/        autoloads, event bus, managers
src/resources/      custom Resource classes + .tres data
debug/              capture harness and dev-only scenes
```
